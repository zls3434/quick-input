# 设计：边缘吸附支持沿边任意位置停靠

## 背景

当前边缘吸附（0.10.x）吸附后沿边方向强制居中（`snapped_position` 中
`(wa_b - wa_t - oh) / 2.0` 或 `(wa_r - wa_l - ow) / 2.0`）。居中停靠可能
遮挡屏幕/窗口边上的关键内容（如全屏应用的底部字幕、窗口侧边工具栏）。
目标：吸附后可停靠于边缘任意位置，避免居中遮挡。

## 决策

采用**沿边方向比例偏移（0~1）**方案（方案 A）：

- 吸附记忆从"仅边名"扩展为"边名 + 沿边偏移比例"；旧配置无偏移字段时
  回退 0.5（居中），行为与现状完全一致，向后兼容。
- 垂直边（screen-top/bottom、win-top/bottom）沿水平方向按比例插值；
  水平边（screen-left/right、win-left/right）沿垂直方向按比例插值。
- 目标窗口沿边移动时，偏移比例保持不变 → 悬浮窗保持相对位置跟随。
- 比例按"应用 + 布局"记忆（`snap_memory` 既有键结构），切换应用回来
  仍停原处。

## 钳制规则（已确认）

- screen-* 边：沿边方向钳制在工作区内，保证完整可见。
- win-* 边：沿边方向钳制在目标窗口投影内（悬浮窗完全包含于窗口投影）；
  窗口投影长度小于悬浮窗时居中兜底。
- 贴合边方向与现有逻辑一致：screen 贴合工作区边（0 间距），win 贴合
  窗口外侧（`SNAP_GAP` 间距）。
- 最终整体仍按现有 `clamp` 保证悬浮窗落在工作区内。

## 改动点

### 1. 配置模型 `src/backend/src/config/model.rs`

- `SnapEdgeSettings` 新增 `horizontal_offset: Option<f64>`、
  `vertical_offset: Option<f64>`（沿边偏移比例，`None` = 0.5 居中）。
- 新增读取方法 `snap_edge_offset(process, layout) -> Option<(String, f64)>`：
  返回边名与生效偏移（无偏移字段回退 0.5）。
- `set_snap_edge` 签名扩展为 `set_snap_edge(process, layout, edge: Option<(&str, f64)>)`：
  `Some((edge, offset))` 写入边 + 偏移；`None` 清除该布局记忆（含偏移）。
  条目清空规则保持现状。
- `validate()`：偏移字段若存在需在 `[0.0, 1.0]` 内，越界报错。

### 2. 位置计算 `src-tauri-app/src-tauri/src/target_window.rs`

- `snapped_position(edge, ow, oh, offset: f64, info, scale)`：
  - 垂直贴合边固定（现有公式），沿边方向：
    - screen 类：`x = wa_l + (wa_r - wa_l - ow) * offset`，
      工作区小于悬浮窗时居中。
    - win 类：`x = wl + (wrr - wl - ow) * offset`，
      窗口投影小于悬浮窗时居中。
  - 水平贴合边同理沿垂直方向插值。
  - 保留现有整体工作区 `clamp`。
- 新增 `offset_from_position(edge, ox, oy, ow, oh, info, scale) -> f64`：
  由悬浮窗当前位置反算沿边偏移（`clamp(0.0, 1.0)`），供拖动命中时记忆。

### 3. 吸附流程 `src-tauri-app/src-tauri/src/window.rs`

- `evaluate_drag_snap`：命中边后调用 `offset_from_position` 反算偏移，
  `DragSnapOutcome::Snapped` 携带 `offset: f64`。
- `handle_drag_end`：Snapped 时经 `write_snap_edge` 写入 `(edge, offset)`，
  落位用 `snapped_position(edge, ow, oh, offset, ...)` 计算（与记忆一致）。
- `write_snap_edge`：参数改为 `Option<(&str, f64)>`。
- `snap_position_for`：改用 `snap_edge_offset` 读取边 + 偏移，传给
  `snapped_position`。
- `current_snap_anchor` / `height_anchor_for_edge`：不变（仍按边决定锚定）。

## 兼容性

- 旧 `snap_memory` 只有边名：读取时偏移回退 0.5，行为不变。
- 拖离解除吸附、重置位置与大小：清除边时同时清除偏移（由 `set_snap_edge`
  `None` 分支与 `snap_memory = None` 覆盖）。
- TOML 新增字段带 `skip_serializing_if = "Option::is_none"`，旧配置无需迁移。

## 测试

- `snapped_position`：
  - offset=0.5 与旧居中结果一致（回归）。
  - offset=0 / 1 贴边端；0.3 插值正确。
  - win 类边窗口投影钳制：offset 使悬浮窗超出投影时拉回。
  - 窗口投影小于悬浮窗时居中兜底。
- `offset_from_position`：0.5 反算 0.5；边界（贴左/贴右）反算 0/1；越界 clamp。
- 配置模型：`snap_edge_offset` 无偏移回退 0.5；`set_snap_edge(None)` 清除
  含偏移；validate 对越界偏移报错。
