# 分组标签 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 QuickInput 增加按钮分组能力：应用画像自定义分组驱动悬浮窗 Tab 标签，按钮级 group 字段供设置界面分组管理。

**Architecture:** 后端 `AppProfile` 新增 `groups: Vec<ButtonGroup>`（组名 + 组内按钮）作为磁盘结构；命令层做归一化——设置界面回显时展平（`flatten`），保存时聚合（`regroup`），悬浮窗 `get_buttons` 返回分组视图 `{ groups, default_buttons }`。前端悬浮窗渲染 Tab 栏（仅当存在分组时），设置界面表单增加分组字段。

**Tech Stack:** Rust（serde/toml）、Tauri 2、Svelte 5、TypeScript。

**设计文档:** `docs/superpowers/specs/2026-08-26-分组标签-design.md`

**约定:** 分组语义——`AppProfile.groups`（画像自定义分组，悬浮窗 Tab 依据）；`ButtonConfig.group`（管理维度，仅设置界面用，不产生悬浮窗 Tab）。未分组按钮归「默认」分组，仅当画像定义了 groups 且存在未分组按钮时显示「默认」标签；画像无 groups 时悬浮窗不显示 Tab 栏（现状）。分组名比较区分大小写；按钮 id 跨组全局唯一（画像内）。

```rust
    /// 把按钮列表（含管理维度 group 值）聚合为「分组 + 未分组」存储结构。
    ///
    /// 分组按按钮 group 值首次出现顺序聚合；空串/空白的 group 视为未分组。
    pub fn regroup(buttons: Vec<ButtonConfig>) -> (Vec<ButtonGroup>, Vec<ButtonConfig>) {
        let mut groups: Vec<ButtonGroup> = Vec::new();
        let mut ungrouped: Vec<ButtonConfig> = Vec::new();
        for btn in buttons {
            let g = btn.group.as_deref().map(str::trim).unwrap_or("");
            if g.is_empty() {
                ungrouped.push(btn);
            } else if let Some(grp) = groups.iter_mut().find(|grp| grp.name == g) {
                grp.buttons.push(btn);
            } else {
                groups.push(ButtonGroup {
                    name: g.to_string(),
                    buttons: vec![btn],
                });
            }
        }
        (groups, ungrouped)
    }

    /// 展平：把 groups 与 buttons 合并为「按钮 + group 值」管理视图（设置界面回显用）。
    ///
    /// 分组内按钮携带其组名（`group: Some(name)`），未分组按钮保持 `group: None`。
    pub fn flattened_buttons(&self) -> Vec<ButtonConfig> {
        let mut out = Vec::new();
        for g in &self.groups {
            for mut b in g.buttons.clone() {
                b.group = Some(g.name.clone());
                out.push(b);
            }
        }
        out.extend(self.buttons.clone());
        out
    }
```

```rust
/// 获取当前配置的按钮分组视图（按当前活动进程匹配）
#[tauri::command]
fn get_buttons(state: tauri::State<AppState>) -> Result<ButtonsView, String> {
    let mgr = state.config_manager.lock().map_err(|e| e.to_string())?;
    let process = state.current_process.lock().map_err(|e| e.to_string())?;
    let config = mgr.config();
    // 命中画像：悬浮窗 Tab 依据画像自定义分组；画像 buttons 为默认分组
    if let Some(profile) = config
        .profiles
        .iter()
        .find(|p| p.process_name.eq_ignore_ascii_case(&process))
    {
        return Ok(ButtonsView {
            groups: profile
                .groups
                .iter()
                .map(|g| GroupView {
                    name: g.name.clone(),
                    buttons: g.buttons.clone(),
                })
                .collect(),
            default_buttons: profile.buttons.clone(),
        });
    }
    // 未命中画像：回退默认映射/默认按钮，无分组视图（前端不渲染 Tab）
    let btns = if !config.default_buttons.is_empty() {
        &config.default_buttons
    } else {
        &config.buttons
    };
    Ok(ButtonsView {
        groups: vec![],
        default_buttons: btns.clone(),
    })
}
```
