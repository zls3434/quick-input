# S130 用户故事：按钮面板渲染

**用户故事**：作为用户，我希望浮层中渲染按钮列表（含自定义标签），以便看到预设快捷按钮。

## 验收标准（Given-When-Then）

- **AC1-1**：Given 应用启动且配置加载完成，When 浮层窗口显示，Then 按钮面板渲染所有按钮，每个按钮显示 `label` 字段。
- **AC1-2**：Given 按钮列表来自 M4 配置，When 渲染，Then 每个按钮使用 `id` 作为唯一标识。
- **AC1-3**：Given 按钮数量超出面板可视区域，When 渲染，Then 面板支持垂直滚动。
- **AC1-4**：Given 在 Tauri 2 中，When 前端通过 `invoke` 调用后端，Then 从 M4 获取按钮列表数据。
- **AC1-5**：Given 浮层窗口（M1），When 面板渲染，Then 按钮布局在浮层窗口内自适应。

## 任务清单

1. 初始化 Svelte 前端项目，建立 Tauri 前后端通信
2. 实现 `ButtonPanel` 组件：从 M4 读取按钮列表并渲染
3. 定义按钮 UI 样式（简洁、紧凑、半透明）
4. 实现按钮面板滚动（按钮数量超出时）
5. 实现 Tauri 命令 `get_buttons` 从前端 invoke 获取按钮数据
6. 编写前端组件测试

## 关联需求

- V1 即点即输，不打断输入焦点
- V2 置顶透明浮层，随时可达

## 技术路由

- 前端 Svelte 程序员：按钮面板组件
- 后端 Rust 程序员：Tauri command 桥接 M4
- 依赖 S101（配置加载）、S110（窗口创建）
