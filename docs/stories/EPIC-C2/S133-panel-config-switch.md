# S133 用户故事：配置切换时自动刷新按钮列表

**用户故事**：作为用户，我希望配置切换时按钮列表自动刷新，以便在不同应用看到对应按钮集。

## 验收标准（Given-When-Then）

- **AC4-1**：Given 面板已渲染当前配置按钮，When 收到 `ConfigSwitched` 事件，Then 自动重新加载配置并刷新按钮列表。
- **AC4-2**：Given 配置切换刷新，When 按钮列表变化，Then 面板 UI 平滑过渡（无闪烁）。
- **AC4-3**：Given 配置切换后，When 新配置按钮少于之前，Then 面板正确显示剩余按钮，无残留。
- **AC4-4**：Given 配置切换后，When 新配置按钮多于之前，Then 面板正确显示全部按钮，支持滚动。

## 任务清单

1. 前端监听 Tauri 事件 `ConfigSwitched`
2. 收到事件后通过 `invoke('get_buttons')` 重新获取按钮列表
3. 实现 Svelte 响应式更新，按钮列表自动刷新
4. 处理切换过渡动画（可选，平滑过渡）
5. 编写测试验证事件驱动刷新

## 关联需求

- V3 按应用自动切换配置
- N6 按当前焦点进程/窗口自动切换配置文件

## 技术路由

- 前端 Svelte 程序员：事件监听 + 响应式更新
- 后端 Rust 程序员：Tauri 事件发射
- 依赖 S130（按钮渲染）、S103（配置切换事件）
