# S132 用户故事：单击按钮触发注入

**用户故事**：作为用户，我希望单击按钮即触发注入，以便快速输入预设内容。

## 验收标准（Given-When-Then）

- **AC3-1**：Given 按钮渲染完成，When 用户单击按钮，Then 调用 M2 注入引擎，将按钮 `content` 字段注入到当前焦点输入框。
- **AC3-2**：Given 注入成功，When 注入完成，Then 按钮不改变焦点（验证 M2 注入后焦点保持）。
- **AC3-3**：Given 注入失败（如权限不足），When 单击，Then 前端不崩溃，可在控制台看到错误日志。
- **AC3-4**：Given 单击按钮时，When 按钮处于可点击状态，Then 触发注入（禁用状态下不触发）。

## 任务清单

1. 实现按钮 `on:click` 事件处理函数
2. 通过 Tauri `invoke('inject_text', { text: button.content })` 调用 M2
3. 实现注入 loading/禁用状态（防止重复点击）
4. 实现注入错误处理（兜底不崩溃）
5. 编写端到端测试验证单击 → 注入流程

## 关联需求

- V1 即点即输，不打断输入焦点
- N2 单击按钮即输入到当前焦点输入框
- TR1 单击注入不改变焦点

## 技术路由

- 前端 Svelte 程序员：单击事件路由
- 后端 Rust 程序员：Tauri command 桥接 M2
- 依赖 S130（按钮渲染）、S121（Windows 注入）
