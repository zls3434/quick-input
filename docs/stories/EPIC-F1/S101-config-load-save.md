# S101 用户故事：配置读取与保存

**用户故事**：作为用户，我希望从配置文件读取并保存按钮配置，以便预设内容持久化并可批量自定义。

## 验收标准（Given-When-Then）

- **AC2-1**：Given 应用启动时，When 读取配置目录下的 `default.toml`，Then 加载按钮列表到内存。
- **AC2-2**：Given 用户修改配置文件后保存，When 应用重新加载，Then 按钮列表反映最新配置（热更新或重启生效）。
- **AC2-3**：Given 配置保存操作，When 写入 `default.toml`，Then 不破坏已有其他字段的数据（最小化写入）。
- **AC2-4**：Given 配置文件不存在时，When 应用首次启动，Then 自动创建带默认样例的 `default.toml`。
- **AC2-5**：Given 配置位于系统用户配置目录，When 跨平台运行，Then 使用各平台惯用路径（Tauri `app_config_dir`）。

## 任务清单

1. 实现 `ConfigManager` struct，维护内存中当前配置
2. 实现配置加载：从 `app_config_dir` 读取 `default.toml`
3. 实现配置保存：序列化并写入文件（原子写）
4. 实现首次启动默认配置生成
5. 实现配置校验错误处理（失败时返回错误，不影响应用其他模块）
6. 编写单元测试覆盖加载/保存/默认生成

## 关联需求

- N7 配置文件持久化与批量自定义
- 概念 V3 配置驱动
