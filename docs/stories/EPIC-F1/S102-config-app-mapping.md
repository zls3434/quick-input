# S102 用户故事：按进程名映射应用配置

**用户故事**：作为用户，我希望配置支持按进程名映射，以便不同应用显示对应按钮集。

## 验收标准（Given-When-Then）

- **AC3-1**：Given 焦点进程名为 `Code.exe`，When 查询配置，Then 返回与 `Code.exe` 关联的配置文件按钮列表。
- **AC3-2**：Given 配置文件中存在 `[[profiles]]`（每项含 `process_name` 与 `buttons`），When 解析，Then 正确建立进程名 → 按钮集的映射。
- **AC3-3**：Given 进程名映射查询，When 进程名匹配，Then 返回对应配置；当无匹配，Then 返回空（交由 S103 兜底）。
- **AC3-4**：Given 进程名大小写不一致，When 匹配，Then 采用大小写不敏感匹配。

## 任务清单

1. 定义 `AppProfile` 结构（含 `process_name`、`buttons`）
2. 实现进程名 → 配置映射查询接口 `get_config_for_process(process_name)`
3. 实现大小写不敏感匹配
4. 定义"未匹配返回 None"契约（供 S103 兜底）
5. 编写单元测试覆盖匹配/不匹配/大小写场景

## 关联需求

- V3 按应用自动切换配置
- N6 按当前焦点进程/窗口自动切换配置文件

## 技术路由
