# S112 用户故事：浮层拖动与调整大小

**用户故事**：作为用户，我希望浮层可拖动位置、可调整大小，以便按需摆放不遮挡内容。

## 验收标准（Given-When-Then）

- **AC3-1**：Given 浮层窗口，When 用户拖拽窗口标题区域（或空白区域），Then 窗口跟随鼠标移动。
- **AC3-2**：Given 浮层窗口，When 用户拖拽窗口边缘或角落，Then 窗口大小随之调整。
- **AC3-3**：Given 窗口大小调整，When 尺寸变化，Then 按钮面板 UI 自适应布局（不溢出）。
- **AC3-4**：Given 拖动后，When 下次启动，Then 记住上次位置与大小（可选，可标记为 P1）。

## 任务清单

1. 使用 Tauri `data-tauri-drag-region` 实现拖动区域
2. 实现窗口缩放（启用 `resizable: true`，设置最小宽高）
3. 前端 Svelte 适配响应式布局（按钮随窗口大小自适应）
4. 实现位置/大小持久化（可选，P1 降级）

## 关联需求

- V2 置顶透明浮层，随时可达
- M1 可拖动、可调整大小

## 技术路由

- 后端 Rust 程序员：Tauri 窗口配置
- 前端 Svelte 程序员：响应式布局
- 依赖 S110 窗口创建
