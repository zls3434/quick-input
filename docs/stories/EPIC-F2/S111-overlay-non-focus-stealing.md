# S111 用户故事：点击不抢焦点

**用户故事**：作为用户，我希望点击浮层按钮时不改变当前输入焦点，以便不打断输入流。

## 验收标准（Given-When-Then）

- **AC2-1**：Given 浮层窗口显示在前台，When 用户点击浮层上的任意位置，Then 当前焦点窗口的输入焦点不被改变。
- **AC2-2**：Given 用户正在输入框输入文字，When 点击浮层按钮，Then 输入框仍保持焦点，可继续输入。
- **AC2-3**：Given 浮层窗口，When 首次创建显示，Then 不激活/不抢占前台，不改变当前焦点。
- **AC2-4**：Given 代码实现，When 点击事件处理，Then 注入前记录原焦点句柄，注入后验证焦点未丢失。

## 任务清单

1. Windows 实现：设置 `WS_EX_NOACTIVATE` 扩展样式，处理 `WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`
2. 使用 `ShowWindow(SW_SHOWNOACTIVATE)` 替代默认激活显示
3. 实现点击时记录原焦点句柄，注入后恢复焦点（双保险）
4. 编写集成测试验证不抢焦点行为

## 关联需求

- V1 即点即输，不打断输入焦点
- N3 点击按钮后不改变当前焦点
