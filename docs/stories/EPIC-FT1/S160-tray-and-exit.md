# S160 用户故事：系统托盘与退出

**用户故事**：作为用户，我希望浮层能最小化到系统托盘并通过托盘菜单控制，以便随时呼出与退出。

## 验收标准（Given-When-Then）

- **AC8-1**：Given 应用运行，When 启动完成，Then 系统托盘显示应用图标。
- **AC8-2**：Given 托盘图标，When 右键点击，Then 弹出菜单，包含"显示/隐藏"与"退出"选项。
- **AC8-3**：Given 点击"显示/隐藏"，When 浮层当前隐藏，Then 显示浮层；当前显示，Then 隐藏浮层。
- **AC8-4**：Given 点击"退出"，When 确认对话框弹出，Then 确认后应用退出，取消则保持运行。

## 任务清单

1. 新建 `tray.rs` 模块，实现托盘图标与菜单
2. 使用 Tauri 2 内置 `TrayIconBuilder` + `Menu`
3. 实现"显示/隐藏"切换浮层窗口
4. 使用 `tauri-plugin-dialog` 实现退出确认
5. 在 `setup()` 中注册托盘
6. 编写单元测试验证菜单动作与窗口状态

## 关联需求

- N8 开机自启（托盘作为常驻入口的前提）
- AC2 系统托盘图标与菜单

## 技术路由

- 后端 Rust 程序员：Tauri Tray API + Menu + Dialog
- 依赖 M1 浮层窗口（显示/隐藏控制）
