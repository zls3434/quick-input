# 系统模块索引

> 本文档将 QuickInput 产品概念分解为可独立开发的模块，定义模块职责、依赖关系、优先级与开发批次。

## 模块总览

| # | 模块名 | 职责 | 优先级 | 开发批次 | 依赖 | 对应 SRS 路径 |
|---|--------|------|--------|----------|------|---------------|
| M1 | 浮层窗口模块 (Overlay Window) | 置顶、可拖动、调整大小、不抢焦点、多显示器支持 | P0 | 第一批 | 无（基础模块） | `srs/overlay-window.md` |
| M2 | 输入注入模块 (Input Injector) | 跨平台文本注入到焦点输入框，不改变焦点 | P0 | 第一批 | 无（基础模块） | `srs/input-injector.md` |
| M3 | 焦点识别模块 (Focus Detector) | 识别当前焦点进程/窗口，映射到配置 | P1 | 第二批 | M4 | `srs/focus-detector.md` |
| M4 | 配置管理模块 (Config Manager) | TOML 解析/保存/批量自定义/按应用加载/默认兜底 | P0 | 第一批 | 无（基础模块） | `srs/config-manager.md` |
| M5 | 按钮面板 UI 模块 (Button Panel UI) | 渲染按钮、悬浮注释、单击事件路由 | P0 | 第一批 | M1, M4, M2 | `srs/button-panel.md` |
| M6 | 应用生命周期模块 (App Lifecycle) | 开机自启、托盘图标、热键呼出/隐藏 | P2 | 第三批 | M1, M4 | `srs/app-lifecycle.md` |
| M7 | 可视化配置界面 (Config GUI) | GUI 增删改按钮，免手改 TOML 文件 | P2 | 扩展 | M4, M5 | — |
| M8 | 共享配置/云同步 (Sharing) | 配置导出/导入/团队共享 | P3 | 未来 | M4 | — |

### 依赖说明

- **M4 → M5**：M5 渲染按钮时从 M4 读取配置
- **M4 → M3**：M3 根据焦点进程从 M4 获取对应配置
- **M3 → M5**：M3 切换配置后通知 M5 刷新按钮列表
- **M5 → M2**：M5 单击按钮时调用 M2 注入文本
- **M5 → M1**：M5 的 UI 渲染在 M1 的浮层窗口中
- **M6 → M1**：M6 控制 M1 的显示/隐藏（热键呼出）
- **M6 → M4**：M6 读取应用生命周期相关配置
- **M1 → 无**：M1 为基础模块，不依赖其他模块
- **M2 → 无**：M2 为基础模块，不依赖其他模块
- **M7 → M4, M5**：扩展模块，依赖配置与面板
- **M8 → M4**：扩展模块，依赖配置数据

### 关键解耦约定

- **M5 不直接依赖 M3**：M5 单击按钮时不触发配置切换，仅调用 M2 注入。配置切换由 M3 在焦点变化事件中驱动，通过 Event Bus 通知 M5 刷新。
- **M3 不直接依赖 M2**：焦点识别只负责"配置映射"，不负责注入。
- **M1 不依赖任何模块**：纯窗口系统层，通过 Tauri 窗口 API 实现。

## 开发批次划分

### 第一批（最小核心验证）

> 目标：完成"单默认配置的置顶浮层，可点击注入"

| 批次 | 模块 | 输出产物 |
|------|------|----------|
| 1.1 | M4 Config Manager | TOML 解析库、单配置加载/保存 |
| 1.2 | M1 Overlay Window | 置顶浮层窗口、不抢焦点、可拖动 |
| 1.3 | M2 Input Injector | 文本注入实现（首期 Windows 平台） |
| 1.4 | M5 Button Panel UI | 按钮渲染、悬浮注释、单击事件路由到 M2 |

### 第二批（加入按应用切换）

| 批次 | 模块 | 输出产物 |
|------|------|----------|
| 2.1 | M3 Focus Detector | 焦点进程/窗口识别、配置映射、切换事件通知 |
| 2.2 | M5 增强 | 接收 M3 切换事件，刷新按钮列表 |
| 2.3 | M4 增强 | 多配置加载、按进程匹配、默认兜底 |

### 第三批（体验增强）

| 批次 | 模块 | 输出产物 |
|------|------|----------|
| 3.1 | M6 App Lifecycle | 开机自启、托盘图标、系统托盘菜单 |
| 3.2 | M1 增强 | 全局热键呼出/隐藏、多显示器适配 |

### 扩展（后续规划）

| 批次 | 模块 | 输出产物 |
|------|------|----------|
| 4.1 | M7 Config GUI | 可视化配置界面 |
| 4.2 | M8 Sharing | 配置导出/导入/团队共享 |

## 模块间通信

- **Event Bus（事件总线）**：M3 焦点切换 → 派发 `ConfigSwitched` 事件 → M5 监听并刷新按钮
- **直接调用**：M5 单击按钮 → 直接调用 M2 注入接口
- **配置获取**：M5/M3 通过 M4 的公开 API 读取/写入配置
- **窗口控制**：M6 通过 M1 的公开 API 控制显示/隐藏/置顶状态

## 术语表

| 术语 | 说明 |
|------|------|
| 配置映射 | 焦点进程名 → 对应 TOML 配置文件的映射关系 |
| 默认兜底 | 焦点进程无匹配配置时，加载 `default.toml` |
| 事件总线 | 模块间解耦的事件通知机制 |
| 开发批次 | 按依赖与优先级划分的开发顺序 |
