# EPIC-C2: 按钮面板交互

## 概述

实现 QuickInput 的按钮面板 UI——在浮层窗口中渲染按钮列表，支持悬浮注释显示，单击按钮触发输入注入。是用户直接交互的界面层，也是核心价值"即点即输"（V1）与"悬浮注释说明"（V4）的直接体现。

## 业务价值

- 支撑核心价值 V1（即点即输）与 V4（悬浮注释说明）
- 用户所见即所得的交互界面，决定产品体验质量
- 作为 M4（配置）→ M2（注入）的交互桥梁

## 验收标准

- [ ] AC1: 在浮层窗口中渲染从 M4 读取的按钮列表
- [ ] AC2: 鼠标悬停按钮时弹出注释说明
- [ ] AC3: 单击按钮后调用 M2 注入预设文本
- [ ] AC4: 按钮列表随配置切换（M3 事件通知）自动刷新
- [ ] AC5: 按钮支持自定义标签（显示名称）
- [ ] AC6: 浮层 UI 简洁、半透明/可自定义透明度

## 范围

- 按钮列表渲染（从 M4 读取配置）
- 悬浮注释实现（Tooltip）
- 单击事件路由到 M2 注入引擎
- 配置切换事件监听与刷新
- **不含**：浮层窗口本身（M1）、输入注入（M2）、配置管理（M4）、焦点识别（M3）

## 技术要点

- 使用 Svelte 渲染 UI，轻量高效
- 悬浮注释用 CSS Tooltip 或 Tauri 原生 Tooltip
- 单击事件调用 M2 注入接口（通过 Tauri `invoke` + Rust 命令）
- 通过事件总线监听 M3 的配置切换事件
