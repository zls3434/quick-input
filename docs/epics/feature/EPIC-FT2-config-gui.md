# EPIC-FT2: 可视化配置管理

## 概述

提供 GUI 可视化配置界面，让用户无需手动编辑 TOML 文件即可增删改按钮、设置注释、管理应用映射。属于 P2 扩展优先级，在核心功能稳定后开发。

## 业务价值

- 降低非技术用户的使用门槛
- 提升配置管理效率，减少手改 TOML 的语法错误
- 为后续配置共享（M8）提供 UI 基础

## 验收标准

- [ ] AC1: UI 界面列出所有按钮，支持增删改
- [ ] AC2: 支持编辑按钮的标签、内容、注释
- [ ] AC3: 支持管理应用映射（哪个进程用哪个配置）
- [ ] AC4: 修改后自动保存到 TOML 配置文件

## 范围

- 配置管理的 GUI 界面
- 按钮增删改操作
- 应用映射管理
- 配置保存与校验

## 技术要点

- 独立窗口或内嵌页，使用 Svelte 渲染
- 通过 M4 的 Rust API 读写配置
- 配置变更实时同步到主浮层
