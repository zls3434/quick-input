# EPIC-FT3: 配置共享与协作

## 概述

提供配置的导出/导入与团队共享能力，支持开发者与运维团队分享常用快捷按钮配置。属于 P3 优先级，当前不进入开发。

## 业务价值

- 团队内共享标准化命令/模板集
- 新人快速上手，减少配置重复劳动
- 为未来云同步预留扩展点

## 验收标准

- [ ] AC1: 支持配置导出为单个 TOML 文件
- [ ] AC2: 支持导入 TOML 配置文件
- [ ] AC3: 导入时校验配置格式，错误时给出提示

## 范围

- 配置导出（选择配置 → 导出 TOML 文件）
- 配置导入（选择 TOML 文件 → 导入到配置目录）
- 导入校验与冲突处理

## 技术要点

- 通过 M4 的 Rust API 导出/导入
- 文件选择对话框（Tauri 原生 dialog）
