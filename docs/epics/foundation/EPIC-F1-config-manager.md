# EPIC-F1: 配置管理基础设施

## 概述

建立 QuickInput 的配置管理基础能力，负责 TOML 配置文件的解析、加载、保存、批量自定义，以及按应用进程映射配置与默认兜底策略。是本项目最底层的基础模块，被按钮面板（M5）、焦点识别（M3）、生命周期（M6）等多个模块依赖。

## 业务价值

- 支撑"按应用自动切换配置"（V3）与"配置文件持久化与批量自定义"（N7）
- 配置驱动整个工具的行为，是其他模块的前置依赖
- 提供批量自定义能力，满足开发者/运维对多套快捷按钮集的管理需求

## 验收标准

- [ ] AC1: 能解析 TOML 配置文件，正确读取按钮列表、注释与应用映射
- [ ] AC2: 支持配置保存与批量编辑（文件级别），不破坏已有数据
- [ ] AC3: 支持按进程名映射到对应配置文件
- [ ] AC4: 当焦点进程无匹配配置时，自动回退加载默认配置 `default.toml`
- [ ] AC5: 配置加载失败时给出明确错误，不影响应用其他模块运行

## 范围

- 配置文件的读取、解析（TOML）、写入、校验
- 多配置文件的组织与按应用映射
- 默认配置兜底策略
- **不含**：按钮面板渲染、焦点识别、输入注入（由其他 Epic 负责）

## 技术要点

- 使用 `toml` crate 解析/序列化
- 配置文件位于用户配置目录（Tauri `app_config_dir`），跨平台
- 提供事件总线钩子，配置切换时通知订阅方
